# LeadPing

Мини-CRM для контроля follow-up по заявкам. Один HTML-файл, без бэкенда.

## 🔗 Демо
https://tyushnyakov1.github.io/leadping/

## Возможности
- учёт заявок: статус, источник, сумма, заметка
- дашборд «сегодня / просрочено / выиграно»
- шаблоны сообщений с подстановкой `{{name}}`
- экспорт в Excel с автошириной колонок
- данные хранятся локально в браузере (localStorage)

## Как пользоваться
Добавить заявку → назначить следующий контакт → каждый день смотреть «Сегодня».
